Pure vs impure vs method — when does transform run?

fruits | joinPure{{ fruits | joinPure }}
fruits | joinImpure{{ fruits | joinImpure }}
joinViaMethod(fruits){{ joinViaMethod(fruits) }}

Each click is an event in this component, so Angular marks this view (and its ancestors) dirty and re-renders it: the impure pipe and the method run every time, the pure pipe only when the array reference changes. After push() the pure row is stale. Even “Reset counters” is a click inside this view, so the impure/method counters restart at 1.
