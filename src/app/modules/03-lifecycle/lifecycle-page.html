Every hook of a component, a directive and a service, logged in the exact order Angular calls them. Each button opens a short "recording window" labelled ▶ in the log.

Things to notice: the constructor sees the input's default value; ngOnChanges runs before ngOnInit; the static @ViewChild is already defined in ngOnInit; afterNextRender phases run once, after all Checked hooks; setting the input directly in TypeScript calls no hook and the OnPush child keeps showing the old value; an event that changes nothing still runs ngDoCheck and the Checked hooks.

A directive has no template, but Angular still calls the content and view hooks on it.

The service defines ngOnInit, ngDoCheck and ngAfterViewInit, yet only ngOnDestroy (and DestroyRef callbacks) are ever called.
